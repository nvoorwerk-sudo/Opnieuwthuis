# Bijdragen aan Opnieuw Thuis

Fijn dat je wilt meedenken. Dit is een klein, bewust simpel project: één
zelfstandig HTML-bestand (`index.html`), zonder build-stap, framework of
dependencies. Bijdragen die dat zo houden, zijn het meest welkom.

## Snel aan de slag

1. Fork de repo en clone 'm lokaal.
2. Open `index.html` gewoon in je browser — geen server of installatie nodig.
3. Pas aan, herlaad de pagina, en test in de live preview van de generator zelf.
4. Maak een pull request met een korte omschrijving van wat en waarom.

## Soorten bijdragen die goed passen

- **Nieuwe kleurthema's** — voeg een object toe aan `THEMES` in
  `index.html` en een `<option>` in de themakeuze.
- **Andere talen** — een vertaalde versie van de generator (bijv.
  `index.en.html`) is welkom als apart bestand; we houden de Nederlandse
  versie als uitgangspunt.
- **Toegankelijkheid** — verbeteringen aan focus states, screenreader-
  labels, contrast, etc.
- **Documentatie** — verduidelijkingen in de `README`, extra
  voorbeeldpagina's zoals `voorbeeld.html`.

## Wat waarschijnlijk niet wordt overgenomen

- Een build-stap, package manager of framework toevoegen — het doel is
  dat iemand zonder technische kennis het bestand nog steeds kan openen
  en begrijpen.
- Een backend of database om aanbiedingen automatisch bij te houden.
  Dat is een bewuste keuze (zie de README) zodat de pagina overal blijft
  werken, zonder server of privacygevoelige opslag. Wil je dat toch
  verkennen, open dan eerst een issue om het idee te bespreken.

## Vragen of ideeën

Open een issue — ook voor een idee waar je nog niet zeker van bent.
